# 排行榜与播放体验改进

本分支基于 LibreSpark/LibreTV 2.16.12，保留上游 AGPL-3.0 许可证。现有设置、观看历史与播放入口继续沿用。

## 首页找片

在设置中把首页推荐数据源选为「影视榜单」。首页提供四个主分类，点击作品即可通过当前配置的影视源搜索。

| 分类 | 内容 |
| --- | --- |
| 电视剧 | 国产剧周榜、海外剧周榜、韩剧口碑榜、百度热播剧 |
| 电影 | 电影口碑周榜 |
| 综艺 | 国内综艺周榜、海外综艺周榜 |
| 动漫 | 全部、国漫、日漫、欧美动画、动画电影；热门 / 口碑、年份、片名和分页 |

分类、最后查看的榜单及动漫筛选保存在当前浏览器或桌面窗口的本地存储中。影片搜索后返回首页，会恢复刚才的筛选。

### 韩剧口碑榜

取豆瓣「韩剧」口碑顺序的前 100 条，与「韩国＋电视剧」目录前 40 条按作品 ID 交叉筛选，保留原口碑顺序，最多展示 20 部，缓存 1 小时。此举减少韩综、动画和错误地区标签的混入。显示名次是本页面筛选后的顺序，并非豆瓣发布的独立韩剧周榜。社区分类仍可能存在误标；任一目录不可用时会提示重试，不冒充其他榜单。

### 动漫目录

目录来自 [Bangumi 公共 API](https://github.com/bangumi/api)，每页 20 条、缓存 30 分钟。地区依赖社区公共标签；「动画电影」按剧场版分类。可检索热门及历年作品，不能保证收录全部作品，也不能保证每个条目都能在配置的片源中播放。

- 「全部」或「动画电影」选「口碑」、不填片名时使用目录接口，可浏览超过 1,000 条的已排名作品。
- 热门、地区和片名筛选使用搜索接口，单个条件最多可浏览 1,000 条，页面明确显示这一限制。按年份或片名缩小范围可继续找其他作品。
- 年份覆盖 1900 年至下一年。旧作品若缺少完整首播日期，可能在地区年份筛选中漏掉；可选「全部＋口碑＋年份」，或取消年份直接搜索片名。
- 评分是 Bangumi 评分；「Bangumi 口碑 #N」为全站动画口碑排名，不是当前地区的列表序号。未评分、未上榜和缺少海报的作品保留相应占位状态。

接口：`GET /api/anime?category=all&sort=heat&year=all&keyword=&page=1`。支持 category `all/china/japan/western/movie`，sort `heat/rank`；沿用站点密码验证，固定上游地址并校验筛选参数。

若部署环境无法直连 `api.bgm.tv`，可在 `.env.local` 设置 `BANGUMI_PROXY_URL` 为受信任的 HTTP(S) 代理地址。它只代理 Bangumi 目录与新番请求，不改变影视播放链路；默认直连。代理凭据只留在服务器配置中，勿提交到仓库。

## 播放与搜索

- 换源时比较当前集的码流信息，区分真实分辨率、码率估算和清单标注。结果用于选择片源，不会把低清内容变成高清，也不会移除片内水印。
- 搜索与换源优先匹配片名、季度、集号和版本，保留不同语言及版本的区别，减少串季、串集。
- 支持跳过片头，以及到片尾时间点后自动播放下一集；默认跳过时长为 90 秒，可在播放器中调整。按时长执行，不是自动识别片头、片尾画面。
- 电影的不同清晰度或语言版本不会作为连续剧集自动连播。
- 减少滚动时的大面积滤镜和阴影动画，图片异步解码，复用卡片渲染，清理弹窗动画回调，支持系统减少动态效果设置。

## 从本分支源码运行

官方发布镜像不包含这里的改动，先检出本分支代码，再按以下步骤构建。需要 Node.js 20.18.1 或更新版本。

```sh
npm ci
cp .env.example .env.local
# 编辑 .env.local，设置自己的 PASSWORD 与需要的 DEFAULT_SOURCES
npm run build
npm start
```

访问 `http://localhost:8080`。已有的本地桌面窗口连接同一服务，服务更新后刷新或重启窗口即可生效。本仓库不包含个人密码、观看记录、第三方源私有配置或本机桌面封装二进制。

## 验证

```sh
npm test
npm run lint
npm run build
```

自动测试覆盖目录参数、分页上限、数据归一、鉴权、韩剧交集筛选、画质解析、季度集号匹配和播放导航。外部目录与第三方播放源会变化；自动测试使用 mock，不能代替当前网络下的实际页面与播放验证。
